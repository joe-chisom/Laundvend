# LaundVend

## Flexible Laundry Vendor Marketplace

LaundVend is a laundry marketplace designed to help households in Lagos find laundry vendors who are actually available when they need a service.

Instead of simply showing a list of laundry businesses, LaundVend focuses on **availability, location, pickup time, pricing, delivery and trust** so customers can compare vendors before making a request.

## Problem

Finding a laundry service when you need one can involve contacting several vendors before discovering who is available.

Customers may need to know:

- Which vendor is available today?
- Where is the vendor located?
- What laundry service do they provide?
- When can they pick up the laundry?
- How much does the service cost?
- Do they offer delivery?
- Can the customer trust the vendor?

LaundVend brings these details together in one place.

## Main Features

### Vendor Availability
Vendors are organised into:

- **Available Today**
- **Available Tomorrow**

This makes it easier for customers to find a vendor based on when they need the service.

### Search and Filters

Users can select:

- Location
- Laundry service
- Pickup time

This helps narrow the vendor options according to the customer's needs.

### Vendor Information

Each vendor card displays:

- Vendor name
- Location
- Service offered
- Pickup time
- Experience
- Rating
- Delivery availability
- Verification status
- Service price
- Delivery fee

### Request Vendor

Each vendor listing includes a **Request Vendor** button, giving the customer a clear next step after comparing the available options.

## Design

LaundVend uses a simple and modern visual identity based on:

- Aqua: `#20C9C3`
- Deep Navy: `#12304A`
- Soft Gray: `#F2F6F8`
- White: `#FFFFFF`

The interface uses rounded vendor cards, subtle borders, recessed shadows and responsive layouts to create a clean marketplace experience.

## Technologies Used

- HTML5
- CSS3

The project is built without JavaScript frameworks or external UI libraries.
